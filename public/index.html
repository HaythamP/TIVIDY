My workflow

Workflow guide (which action should I use?)

Assign → Start: choose a participant while an item is Available, then start it to enter InProgress.

Regular item: Complete moves it to Completed and releases the next step.

Escalation: Start escalation enters Escalated. Next escalation level advances the chain. Resolve escalation finishes escalation; if approval is also required, the item then enters Approval.

Approval: Begin approval starts an approval-only chain. In Approval, Approve / next approver advances one person at a time; the final approval completes the item.

Groups: items in one work group run together. Finish every item in the group before the next workflow step is released.

Reject / Cancel: these stop the item. A rejection from an approval chain can be restarted with Restart approval.
