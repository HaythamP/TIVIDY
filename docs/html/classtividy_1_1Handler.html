Detailed Description

template<typename T>
class tividy::Handler< T >

Handler of the Chain of Responsibility pattern, also the AbstractClass of a Template Method.

handle() is the template method: it asks canHandle(); if true it runs process() and returns itself, otherwise it forwards to the successor. copy() is a second template method (cloneSelf() plus a deep copy of the rest of the chain). Deviation from the textbook: the request carries a position and the decorators advance it one handler per user command (Escalate or Approve), so a chain is walked over several commands. Each handler owns its successor, so deleting the head deletes the chain.
