Detailed Description

template<typename T>
class tividy::LevelHandler< T >

ConcreteHandler: one escalation or approval level held by one participant. It handles the request when the chain position equals its level. Handling is the act of taking responsibility (the decorator records the participant as the current contact), so process() does nothing.
