Detailed Description

template<typename T>
class tividy::WorkGroup< T >

Composite of the Composite pattern: a stage that contains other components.

All components directly inside a group run in parallel; the group is complete once every child is complete. Sequencing between steps is handled by the Mediator. A group owns and deletes its children and rejects item-only operations. Visitors see a group once, followed by its children.
