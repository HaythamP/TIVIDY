Detailed Description

template<typename T>
class tividy::TreePrinter< T >

ConcreteVisitor: prints the structure of the workflow as indented text. Groups are printed as + [Group] name (id), items as * name (id) [State], indented by their depth; decorators add tags such as {Audited, Escalation, Approval} to their item's line, and assignees are listed after <-. Unlike ProgressReport it does not count; it shows the shape and the state of every component.
