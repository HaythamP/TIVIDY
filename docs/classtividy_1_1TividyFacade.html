Detailed Description

template<typename T>
class tividy::TividyFacade< T >

Facade: one simple entry point for the subsystem (builder, director, prototype, commands, visitors) so a GUI or main() does not have to know the individual classes. It is optional: every operation can also be done directly with the subsystem classes.

It owns one WorkflowBuilder. Workflows it returns belong to the caller. Every command method looks the component up by id (ComponentNotFoundException if unknown), creates the matching command and executes it through the workflow's history, which prints what happens. Assignment comes in two forms: assignWithStrategies() always selects from the workflow's entire participant pool; assignToParticipants() is used when no strategies are given and takes the participants explicitly. Escalation and approval participants become chains (the facade adds the FallbackHandler to escalation chains).
