Detailed Description

template<typename T>
class tividy::WorkComponent< T >

Common interface of the workflow tree: Component of the Composite pattern, Component of the Decorator pattern, Element of the Visitor pattern, Originator interface of the Memento pattern and Colleague of the Mediator pattern.

A workflow is a tree of WorkGroup (composite) and WorkItem (leaf) objects. Decorators (AuditedWork, EscalatedWork, ApprovedWork) wrap a WorkItem and are themselves WorkComponents, so clients treat decorated and plain items identically. Operations that only make sense for an individual item (start, complete, assign, ...) throw UnsupportedOperationException by default; WorkItem and the decorators override them. Groups therefore reject commands. Ownership: parent and mediator are non-owning back references. Children are owned by their WorkGroup (or by the WorkflowDefinition for top-level steps).

Ttype of component ids (int or std::string).

template<typename T >

const std::vector< AssignmentStrategy< T > * > &  strategies,
int  numAssignees = -1 
) const
virtual

Selects assignees without changing anything (Strategy pattern).

The candidates are the given pool; each strategy filters the result of the previous one in list order; then numAssignees are chosen (the first ones, or random ones if a RuleAssignment is present). Pass -1 to select everyone left.

Exceptions
InvalidAssignmentArgumentExceptionfor invalid arguments.
InsufficientParticipantsExceptionif too few candidates remain.
