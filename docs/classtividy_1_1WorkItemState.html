Detailed Description

template<typename T>
class tividy::WorkItemState< T >

State of the State pattern: behaviour of a WorkItem in one lifecycle state.

Every transition method throws InvalidTransitionException by default; concrete states override exactly the transitions they allow and call WorkItem::setState() as their last statement to move to the next state. States are stateless value objects: they are created by other states, owned by one WorkItem (or Memento) and deleted by WorkItem::setState(). Lifecycle (see WorkItem for the table): Created, Available, Assigned, InProgress, then Escalated or Approval, ending in Completed, Rejected or Cancelled.
