Detailed Description

template<typename T>
class tividy::EscalatedWork< T >

ConcreteDecoratorA: adds escalation to a work item and acts as the client of an escalation Chain of Responsibility.

The chain (installed by AssignCommand) is made of LevelHandlers followed by one FallbackHandler. Each Escalate command moves one link forward:

  • the first command moves InProgress to Escalated, starts the chain and passes the request to the first handler in the same step;
  • every further command means the previous handler could not resolve it, so the next handler takes over;
  • when the next handler is the FallbackHandler the escalation completes immediately;
  • a Complete command stops the traversal (a handler resolved the request). Resolving the escalation completes the item, or, if the item is also an ApprovedWork, hands it over to the approval chain (Escalate, then Approve, then Completed). Reject and Cancel stop the escalation. The decorator owns the chain; position and the current contact are saved in mementos so undo works.
