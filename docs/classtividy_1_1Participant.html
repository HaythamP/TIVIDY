Detailed Description

template<typename T>
class tividy::Participant< T >

A person (or resource) that can be assigned to work items.

Participants are owned by the application, never by a workflow: one participant can work in several WorkflowDefinition objects and every pointer to a Participant inside TIVIDY is non-owning. The workload counter is maintained automatically by WorkItem: it grows when the participant is assigned and is released when the item reaches Completed, Rejected or Cancelled (and re-acquired when an item restarts or an undo restores it).
