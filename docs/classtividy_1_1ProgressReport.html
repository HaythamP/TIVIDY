Detailed Description

template<typename T>
class tividy::ProgressReport< T >

ConcreteVisitor: counts items and tallies items per state, then summarises how far the workflow is (for example 3/5 items completed (Completed: 3, ...)). It computes a snapshot on demand and stores nothing in the tree; compare AuditedWork (history of one item) and TreePrinter (shows the structure).
