Detailed Description

template<typename T>
class tividy::ApprovedWork< T >

ConcreteDecoratorA: adds a multi-level approval to a work item and acts as the client of an approval Chain of Responsibility.

The chain contains only LevelHandlers (one per approver, no fallback). Each Approve command moves one link forward:

  • the first command moves InProgress (or Escalated) to Approval, starts the chain and passes the request to the first approver in the same step;
  • every further command means the previous approver signed off and the next approver takes over;
  • when the approver reached is the last one the item completes immediately, so N approvers need N Approve commands. complete() is refused until approval has finished. Reject and Cancel are allowed during approval; an item rejected from Approval stays Rejected (halting the workflow) until the Start command restarts it, which also restarts the approval chain.
