Detailed Description

template<typename T>
class tividy::WorkCommand< T >

AbstractClass of a Template Method, base of all work-item commands and Caretaker of the Memento pattern.

execute() is the template: print the command, collect the affected components, take a memento of each, call the primitive perform(), record the resulting states and roll back if something throws. undo() is the second template: it checks canUndo() and restores the mementos in reverse order. A command may be undone only if every affected component is still in the exact state the command left it, and the affected components include the successor items a completion may have released. Commands target WorkItems (decorated items included); a group target throws UnsupportedOperationException. The command owns its mementos; the target is a non-owning pointer.
