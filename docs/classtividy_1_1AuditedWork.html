Detailed Description

template<typename T>
class tividy::AuditedWork< T >

ConcreteDecoratorB (behavioural decorator): keeps a history of what happened to one work item.

After every successful operation (release, assign, start, complete, reject, cancel, escalate, approve) an entry such as start: Assigned -> InProgress is appended; undoing a command appends an undone entry. Users can also add, edit and delete entries by hand. Difference to ProgressReport: AuditedWork is a per-item, stored history over time that belongs to the item; ProgressReport is a visitor that computes a one-off summary of the whole workflow's current state and stores nothing in the tree.
