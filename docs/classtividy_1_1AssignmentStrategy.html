Detailed Description

template<typename T>
class tividy::AssignmentStrategy< T >

Strategy of the Strategy pattern: one rule that narrows the candidates for an assignment.

WorkItem::assignWork() is the Context: it applies the supplied strategies in list order, each one filtering the result of the previous one, and then selects the assignees. Strategies are passed per assignment and are never stored; the caller owns them. Strategies are used when assigning from the workflow's whole participant pool. If you want to choose participants yourself, pass an explicit participant list instead and no strategies.
